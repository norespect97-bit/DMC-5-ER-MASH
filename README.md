# Elden Ring x Devil May Cry 5 (working title)

> STATUS: SOURCE-ONLY DESIGN, NOT BUILT, NOT TESTED. No playable release exists yet.

Play the whole Elden Ring campaign as Dante or Vergil, chosen at the start.

## Planned features
- **Vergil**: katana kit, fast draw-and-slash timing, blue-toned armor.
- **Dante**: heavy-sword kit, combo-focused, red-toned armor.
- **Devil Trigger**: timed power-up (buff + visual effect), activated by button press.
- **Style rank** D to SSS on screen, tied to damage dealt and taken.
- Controls as close to DMC5 as possible (stretch goal; fallback: Devil Trigger on a spare button).
- Solo only.

## Requirements
- Elden Ring (host game). Runs through ModEngine2, offline, with Easy Anti-Cheat off.
- Devil May Cry 5 is inspiration only and is NOT required.
- No Capcom assets are included.

## Repo layout
- `design/` : source-of-truth sheets (JSON) and `preflight.py`. Change the sheet before the code.
- `src/` : build output and plugin code (empty so far).
- `HANDOFF.md` : what remains to be done.
